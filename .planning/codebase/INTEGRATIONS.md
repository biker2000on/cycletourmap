# External Integrations

**Analysis Date:** 2026-01-24

## APIs & External Services

**Strava API:**
- Service: Strava activity data integration
- What it's used for: Importing cycling activity records, athlete profile data, and real-time activity syncing
- SDK/Client: Axios HTTP client (direct REST API calls)
- Auth: OAuth 2.0 with authorization code flow
  - Env vars: `VUE_APP_STRAVA_CLIENTID`, `VUE_APP_STRAVA_CLIENT_SECRET`
  - Scope: `read,profile:read_all,activity:read`
  - Token endpoint: `https://www.strava.com/oauth/token`
  - API endpoint: `https://www.strava.com/api/v3`
- Endpoints used:
  - `POST /oauth/token` - Exchange code for tokens, refresh tokens
  - `GET /api/v3/athlete` - Get authenticated athlete profile
  - `GET /api/v3/athlete/activities` - List athlete activities with pagination

**Google Maps API:**
- Service: Google Maps geospatial tiles and mapping
- What it's used for: Map tiles displayed via Leaflet
- SDK/Client: leaflet.gridlayer.googlemutant (Leaflet plugin)
- Auth: API key in environment variable
  - Env var: `VUE_APP_GOOGLE_MAPS_APIKEY`
  - Script injection: Dynamically loaded at runtime in `src/components/Leaflet.vue`
- Endpoint: `https://maps.googleapis.com/maps/api/js`

**Google Fonts:**
- Service: Roboto font CDN
- What it's used for: Typography - Roboto font family
- Integration: webfontloader library
- Configured in `src/plugins/webfontloader.js`

## Data Storage

**Databases:**
- **PostgreSQL 14 with PostGIS extension**
  - Provider: Docker image `postgis/postgis:14-master`
  - Connection: `postgresql://cyclist:cyclist@192.168.4.134:5432/cycletourmap`
  - Client: PostGraphile (auto-generated GraphQL interface)
  - Client library: Apollo Client v3 (@apollo/client)
  - Configuration: `tusker.toml` (migration tool config)

**Schema Tables:**
- `Tour` - Cycle tour/trip records with date ranges
- `Activity` - Strava activity data (cycling rides)
- `Auth` - OAuth token storage for Strava authentication
- `Athlete` - User profile information from Strava

**File Storage:**
- Local filesystem only (not external storage service)

**Caching:**
- Apollo Client cache (in-memory)
- Fetch policy: `cache-and-network` (default)

## Authentication & Identity

**Auth Provider:**
- Strava OAuth 2.0
- Implementation: Authorization code flow with refresh tokens
- Files: `src/components/AuthStrava.vue`, `src/components/Strava.vue`

**Backend Auth:**
- JWT-based authentication via PostGraphile
- JWT secret: `myverysecurestring` (hardcoded, see CONCERNS)
- Roles: `anon` (unauthenticated), `webuser` (authenticated)
- Token identifier: `public.jwt_token`

**Credentials Storage:**
- Strava tokens stored in `Auth` table in PostgreSQL
- Access tokens, refresh tokens, and expiration tracked
- Token refresh logic in `src/components/AuthStrava.vue` and `src/components/Strava.vue`
